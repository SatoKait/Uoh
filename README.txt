本プロジェクトを正常に動作させるには「Libs」フォルダの配置が必要です。
お手数ですが、以下の手順に従って準備をお願いいたします。

------------------------------------------------------------
■ 配置手順
------------------------------------------------------------
1- 添付の「Libs」フォルダを解凍してください。
2- 解凍した「Libs」を、現在のフォルダより一つ上の階層に配置してください。

------------------------------------------------------------
■ フォルダ構成イメージ
------------------------------------------------------------
[親フォルダ]
  ├── Libs/		<-- 【ここに配置】
  └── Tobiuou/	<-- (今このテキストがあるフォルダ)

------------------------------------------------------------
■ 注意事項
------------------------------------------------------------
・「Libs」フォルダには、プログラムの動作に必要な外部ライブラリが含まれています。
・配置が正しくない場合、エラーによりビルドできない可能性があります。

何卒よろしくお願いいたします。
